# My Skills — 범용 스킬 모음

특정 목적에 묶이지 않는 Claude Code 스킬을 모아 둔 플러그인입니다.

## 설치

```
/plugin marketplace add kimjunyoung90/claude-plugins
/plugin install my-skills@kimjunyoung90
```

업데이트는 `/plugin marketplace update kimjunyoung90`, `/plugin update my-skills@kimjunyoung90`, `/reload-plugins` 순서로 실행합니다.

## 스킬

| 스킬 | 하는 일 |
|---|---|
| `/my-skills:step-by-step` | 물어보거나 요청할 것이 여러 개일 때 한 메시지에 하나씩 차례로 주고받습니다 |
| `/my-skills:simplify` | 바로 앞 답변을 3~5줄로 짧게 다시 보여 줍니다 |
